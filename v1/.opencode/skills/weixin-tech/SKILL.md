# weixin-tech — 微信公众号技术文章采集技能

## 使用场景

当需要从微信公众号采集当日技术文章（AI/LLM/Agent 相关）并整理为结构化数据时，使用此技能。适用于采集 Agent 的微信公众号采集任务，输出可被下游分析 Agent 直接消费的 JSON 文件。

---

## 执行步骤

### 第 1 步：搜索技术文章

通过搜索引擎或微信公众号文章聚合源搜索当日 AI/LLM/Agent 相关技术文章：

- 使用 `WebFetch` 抓取可访问的微信公众号文章聚合源、技术社区转载页或搜索引擎结果页
- 搜索关键词建议：`AI`、`LLM`、`Agent`、`大模型`、`机器学习`、`RAG` 等
- 日期使用**前一天**到**当天**的窗口，确保覆盖完整采集周期

### 第 2 步：提取信息

从搜索结果中提取每篇文章的以下字段：

- **name**：文章标题
- **url**：文章完整链接（优先使用公众号原文链接，无法访问时使用可用的转载/聚合链接）
- **summary**：文章核心内容的中文摘要
- **created_on**：文章发布日期（格式 `YYYY-MM-DD`）

### 第 3 步：过滤

仅保留满足以下条件的文章：

- **纳入**：内容与 AI、LLM、Agent、大模型、机器学习、深度学习、RAG 等强相关
- **排除**：广告、营销、招聘、课程推广等商业推广性质文章
- **排除**：纯新闻转载无技术含量、内容空洞、标题党的低信息密度文章

### 第 4 步：去重

- 与 `knowledge/raw/` 中已有日期文件中同 `url` 或同 `name` 的条目做比对
- 已采集过的文章跳过，不重复纳入
- 对内容高度相似（同源转载、洗稿）的文章仅保留质量最高的一条

### 第 5 步：撰写中文摘要

为每条保留的文章撰写中文摘要，遵循固定公式：

```
文章主题 + 核心内容 + 为什么值得关注
```

- **核心内容**：基于文章正文提炼关键观点与技术细节，禁止臆测
- **为什么值得关注**：点出文章在 AI/LLM/Agent 领域的价值、创新点或实践参考意义
- 摘要使用流畅中文撰写，不直接翻译英文原文，控制在 100-200 字

### 第 6 步：排序取 Top10

- 按文章质量、时效性与相关度综合排序（优先当天发布的 AI/LLM/Agent 核心文章）
- 截取前 **10** 篇文章作为最终结果

### 第 7 步：输出 JSON

将结果按指定 JSON 结构写入 `knowledge/raw/weixin-tech-YYYY-MM-DD.json`，日期使用采集当日日期。

---

## 注意事项

- **遵守频率限制**：两次采集间隔不得低于 30 分钟，遵守目标网站的使用条款与 `robots.txt`
- **不编造数据**：`name`、`url`、`summary`、`created_on` 必须来自实际搜索结果，禁止虚构
- **禁止硬编码密钥**：若需微信公众号 Token，从环境变量注入，不得写入技能文件或代码
- **写入路径约定**：输出文件必须位于 `knowledge/raw/` 目录下，命名格式 `weixin-tech-YYYY-MM-DD.json`，不得更改
- **源标识**：输出中 `source` 固定为 `weixin_tech`，`skill` 固定为 `weixin-tech`，便于下游追溯

---

## 输出格式

```json
{
  "source": "weixin_tech",
  "skill": "weixin-tech",
  "collected_at": "2026-07-19T08:30:00Z",
  "items": [
    {
      "name": "文章标题",
      "url": "https://mp.weixin.qq.com/s/xxxxx",
      "summary": "xxx：围绕 ... 展开，提出了 ...，在 ... 场景下具有实践价值，值得关注。",
      "created_on": "2026-07-19"
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `source` | `str` | ✅ | 信息来源，固定为 `weixin_tech` |
| `skill` | `str` | ✅ | 使用的技能名称，固定为 `weixin-tech` |
| `collected_at` | `str` | ✅ | ISO 8601 采集时间 |
| `items` | `list` | ✅ | 文章列表，最多 10 条 |
| `items[].name` | `str` | ✅ | 文章标题 |
| `items[].url` | `str` | ✅ | 文章完整链接 |
| `items[].summary` | `str` | ✅ | 中文摘要（100-200 字） |
| `items[].created_on` | `str` | ✅ | 文章发布日期（`YYYY-MM-DD`） |
