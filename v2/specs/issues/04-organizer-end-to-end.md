# 04 — organizer 整理端到端

**What to build:** 流水线中真实的整理阶段：读取当日已分析条目，执行多维去重（id 已存在跳过、source_url 同 URL 仅保留最新、标题相似度 ≥80% 标记疑似重复并记日志）与格式标准化（必填字段校验、score/importance 映射校验、标签去空格、id 不可变性校验），将条目归档为 `{date}-{source}-{slug}.json` 单文件格式。为 importance 为 high 的条目生成 Markdown 分发摘要（150 字内，含标题、亮点、原链接），作为对外分发数据。阶段结束输出归档日志（处理/新增/跳过/错误/已发布计数）。产出物为 JSON 归档 + 分发摘要（PRD 中的「整理成 MD」按此落地）。

**Blocked by:** 01 — 流水线编排骨架与运行清单；03 — analyzer 分析端到端

**Status:** ready-for-agent

- [ ] 读取当日已分析条目，执行 id/URL/标题相似度三维去重
- [ ] 必填字段、score/importance 映射、标签规范性、id 不可变性校验全部通过，问题条目记录错误
- [ ] 按 `{date}-{source}-{slug}.json` 单条一文件归档，符合 01 的已分析文件契约
- [ ] high 条目生成 ≤150 字 Markdown 分发摘要，含标题、核心亮点与原链接
- [ ] 输出归档日志，包含处理/新增/跳过/错误/已发布计数
- [ ] 阶段状态与错误明细正确写入运行清单
