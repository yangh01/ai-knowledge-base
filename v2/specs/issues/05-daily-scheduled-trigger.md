# 05 — 每日定时触发

**What to build:** 让整条流水线每天 UTC 0:00 自动运行，无需人工干预：通过 GitHub Actions 的 schedule cron（`0 0 * * *`）触发工作流，工作流内以指定日期运行流水线入口，将运行清单作为工件输出以便事后核对。提供手动触发途径（workflow_dispatch 或本地命令），用于补跑失败日期。需要处理时区：按 UTC 0:00 触发，运行时按该 UTC 日期执行，不跨天。重跑能力复用 01 的幂等语义。

**Blocked by:** 01 — 流水线编排骨架与运行清单；02 — collector 采集端到端；03 — analyzer 分析端到端；04 — organizer 整理端到端

**Status:** ready-for-agent

- [ ] GitHub Actions 工作流按 UTC 0:00 定时触发整条流水线
- [ ] 支持手动触发，且可指定日期运行
- [ ] 运行清单（含失败日期）可作为工作流产物查看
- [ ] 全链路（采集→分析→整理）无人干预成功率 ≥90%（连续 N 天运行统计，N 在实现中确定）
